# Library Management Console App

## Overview

A C# console application that allows users to manage a small library inventory.

Users can create books, manage available copies, rent books, return books, and view book information through a menu-driven interface.

This project was developed as a final academic project to practice object-oriented programming principles and application development using C#.


## Features

- Create new books
- Display book details
- Add copies of a book
- Remove copies of a book
- Rent available books
- Return rented books
- Input validation
- Inventory tracking
